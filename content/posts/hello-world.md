This site is a static export, so writing happens locally and publishing happens
through git. Run `npm run dev`, open `/studio`, type, and hit **Save**.

## How it works

- The studio writes markdown into `content/posts/`.
- **Commit & push** pushes the change to `main`.
- GitHub Actions rebuilds and deploys to Pages.
